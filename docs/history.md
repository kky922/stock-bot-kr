# Development History

## 안정성 개선

- KIS 접근 토큰의 인스턴스·공유 캐시 만료 처리를 통일했습니다.
- 계좌 포지션과 봇 슬롯을 양방향으로 동기화했습니다.
- 주문 진행 잠금과 재진입 대기시간을 추가했습니다.
- API 장애 상태를 한국장과 미국장으로 분리했습니다.

## 신호 품질 개선

- 뉴스 후보가 기술 분석 단계까지 일봉 데이터를 유지하도록 수정했습니다.
- 시장 국면, 거래량, 추세, 변동성, 지지·저항 검증을 진입 경로에 연결했습니다.
- 손익분기점과 트레일링 스톱 상태를 동기화 후에도 보존하도록 수정했습니다.

세부 동작은 테스트 이름과 현재 코드가 기준입니다. 이 문서는 과거 운영 로그가 아니라
주요 설계 변경의 배경만 기록합니다.
