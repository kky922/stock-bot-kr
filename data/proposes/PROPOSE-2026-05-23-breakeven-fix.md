# PROPOSE: Breakeven Protection Threshold Fix

**현황:** Breakeven 보호(원금보호)가 너무 낮은 임계값에서 활성화되어 정상적인 가격 변동성에도 즉시 손절됨.

## 문제 분석

### 발현 패턴
진입 후 +0.3~0.5% 상승 → breakeven 활성화(SL=진입가) → 수분 내 정상 변동성으로 진입가 도달 → 손절(0% PnL)

### 현재 설정
- `BREAKEVEN_ACTIVATE_PCT` = 1.0% (기본)
- `BREAKEVEN_MIN_PCT` = 0.3% (ATR 높은 종목용 최소값)

### ATR 비율별 실제 임계값
| ATR 비율 | 현재 임계값 | 결과 |
|----------|-----------|------|
| 3% | 1.0% | OK |
| 6% | 0.4% | 너무 낮음 → 즉시 손절 |
| 10% | 0.3% | 사실상 무의미 |
| 16% | 0.3% | 노이즈에 즉시 활성화 |

### 증거 (2026-05-22)
```
10:28:20 씨젠(ATR 16.3%): 원금보호 +0.3% → 12분 후 손절 -0.1%
10:38:44 현대모비스(ATR 10.6%): 원금보호 +0.5% → 8분 후 손절 -0.2%
10:49:54 현대차(ATR 8.5%): 원금보호 +0.3% → 8분 후 손절 0.0%
11:04:37 LX세미콘(ATR 6.1%): 원금보호 +0.5% → 18분 후 손절 0.0%
```

전체 PnL: 손절 -893,280원 (20회, 승률 5%), 트레일링 +1,230,450원 (11회, 승률 100%)

**핵심 통찰:** 진입 자체는 좋다(트레일링 100% 승률). 문제는 breakeven이 너무 빨리 활성화되어 진입을 이른 폐기하는 것.

---

## 제안

### 변경 1: `BREAKEVEN_ACTIVATE_PCT`: 1.0% → **3.0%**
- +3% 이상 상승해야 SL을 진입가로 올림
- 하루 ATR이 6~8%인 KR 종목에 +3%는 의미 있는 상승이지만 과하지 않음
- 트레일링 활성화(5%)에 도달할 시간을 줌

### 변경 2: `BREAKEVEN_MIN_PCT`: 0.3% → **1.0%**
- 고변동성 종목도 최소 +1%는 필요
- ATR 16%인 씨젠도 +1%는 달성 가능하나 진입 후 첫 틱 소음으로는 활성화되지 않음

### 새로운 ATR 비율별 임계값
| ATR 비율 | 새 임계값 | 평가 |
|----------|----------|------|
| 3% | 3.0% | 충분한 상승 확인 후 보호 |
| 6% | 2.4% | ATR 대비 합리적 |
| 10% | 1.6% | 고변동성 종목 보호 |
| 16% | 1.0% | 극단 변동성도 최소 1% 필요 |

### 기대 효과
- **단기:** 0% PnL 마이크로-손절 4건/일 → 0건 (진입 유지)
- **중기:** 일부가 트레일링(100% 승률) 도달 → PnL +200,000~+400,000/월
- **장기:** 슬롯 회전율 감소 → 진입 품질 개선

### 리스크
- **손실 확대 위험:** breakeven이 늦어져 -2~3% 손실 가능 (현재 -0~1% 대비)
  - 그러나 기존 SL(-7~-12%)이 그대로 적용되므로 최대 손실폭은 동일
  - breakeven은 단지 중간 보호막 역할 — 핵심 방어는 ATR 기반 SL
- **롤백 용이성:** config.py 단일 파라미터 변경, 재시작만으로 적용 가능
